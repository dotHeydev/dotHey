# Skills

| Skill | What it does |
|---|---|
| `hey-onboard` | Onboards the agent to the project |
| `hey-ready` | Prepares the context from what you tell it |
| `hey-document-feature`, `hey-draft-feature-plan`, `hey-write-feature-tests`, `hey-implement-feature`, `hey-build-full-feature` | The feature workflow |
| `hey-document-decision` | Turns a settled question into a decision |
| `hey-create-task` | Turns a piece of work into a task |
| `hey-xray` | Holds a long discussion in a file |
| `hey-learn` | Makes a correction you gave last, for every session, harness, and teammate |
| `hey-housekeeping` | Realigns docs, decisions, tests, and code |
| `hey-tools` | Points agents at `bash hey` for every dotHey operation, and at each command's `--help --json` |
